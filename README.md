## 📌 Problem Statement

College students manage assignments, study schedules, deadlines, campus events, announcements, and lost-and-found information across fragmented WhatsApp groups, notebooks, LMS portals, and email threads.

This causes:
- Missed deadlines and assignment panics
- Poor time management and study burnout
- Fragmented communication where important college circulars get buried
- Difficulty finding lost items on campus (calculators, ID cards, chargers)

---

## 💡 Solution: CampusMate AI

CampusMate AI unifies a student's entire academic and campus life into one intelligent, sleek platform inspired by Linear, Notion, and modern SaaS dashboards.

### ✨ The Key Differentiator: "What's Next?" Recommendation Engine
Unlike a static to-do list, CampusMate AI constantly evaluates:
1. **Deadline Proximity:** High-priority assignments due within 24–48 hours.
2. **Current Progress:** Detects deliverables at 0% progress (e.g. *Engineering Mechanics assignment due tomorrow*).
3. **1-Click Actionable Triggers:** Launches a 45-minute focused Pomodoro study sprint with one tap.

---

## 🚀 Key Features

- **🌐 Modern SaaS Landing Page:** Visually stunning hero with interactive dashboard mockup, feature highlights, and a 4-step loop (*Plan → Prioritize → Act → Improve*).
- **🔐 Complete Authentication System:** Clean two-column Login & Registration flow with form validation, password visibility toggles, Forgot Password screen, and a **1-Click Judge Demo Login** button.
- **✨ "What's Next?" Dynamic Card:** Prominent dashboard card with live priority calculations and interactive scenario toggles for judging (*Due Tomorrow*, *Exam Crunch*, *Hackathon Eve*, *All Cleared*).
- **🤖 CampusMate AI Assistant:** Full-page chat advisor with suggested prompts (*"Create a study plan for my exams"*, *"What should I study today?"*, *"Help me prioritize my assignments"*), structured markdown schedules, and optional Gemini API integration.
- **📚 Study Planner & Pomodoro Focus Suite:** Custom timer intervals (25m / 45m / 60m), daily study goal progress rings, ambient focus sounds (*Rain*, *Library Cafe*, *Lo-Fi*), and full lecture timetable.
- **📝 Assignments & Coursework:** List view & Kanban board modes, priority badges, and an **"AI Breakdown"** tool that breaks any assignment into actionable subtasks.
- **📅 Campus Events & Hackathons:** Discover hackathons, workshops, and sports meets with instant RSVP toggles, confetti celebrations, and `.ics` Google/Apple calendar exports.
- **🔎 Lost & Found Community Board:** Centralized recovery board for ID cards, scientific calculators, and laptops with verified contact modals.
- **📢 Announcements & Notices:** Official department notices (Exam Cell, Placement, Dean's Office) with urgency indicators and simulated PDF downloads.
- **📊 Productivity Analytics:** Interactive Recharts charts (Weekly study hours bar chart, subject distribution pie chart, completion trends, 7-day streak records, and AI Burnout Prevention Diagnostics).
- **🌓 Dark Mode & Spotlight Search (`⌘K` / `Ctrl+K`):** Complete theme switching and instant search across all campus entities.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS, PostCSS, Autoprefixer
- **UI Components:** Custom components inspired by Linear & Notion
- **Icons:** Lucide Icons (`lucide-react`)
- **Visualizations:** Recharts
- **Micro-Interactions:** Canvas Confetti, custom animated counters
- **State & Persistence:** React Context API + LocalStorage persistence

## 🏃 Getting Started Locally

### Prerequisites
- Node.js (v20+ recommended)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/rohanmakasare12-tech/rohan-makasare.git
cd rohan-makasare

# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.
